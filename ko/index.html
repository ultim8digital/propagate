교환 조건

물건과 서비스. 돈 없이.

한 묶음 전체

표시된 수량을 한꺼번에 교환해요. 수량을 바꾸려면 별도 게시물을 만드세요.

서비스

각 서비스에 결과 확인 기준과 미래 기한을 추가하세요

교환 완료

각자 자신의 몫을 전달했거나 완료했다고 표시합니다. 받는 사람은 합의한 수량 전체를 받았음을 확인합니다.

물건 · 물건은 직접 전달해야 해요. 서비스가 온라인이어도 두 게시물의 도시는 같아야 해요.

커뮤니티 규칙

도시 선택

도시를 직접 선택하거나 일회성 위치 조회를 허용하세요. 앱은 도시와 대략적인 좌표를 저장하며 백그라운드에서 위치를 추적하지 않습니다. 공개 게시물에 정확한 주소나 개인 연락처를 넣지 마세요.

온라인 서비스

대면 또는 온라인. 각 서비스에 결과 확인 기준과 미래 기한을 추가하세요

내 게시물을 보려면 로그인하세요

둘러보기에는 로그인이 필요하지 않습니다. 게시와 교환에는 iCloud, 프로필과 규칙 동의가 필요합니다. Apple은 앱 전용 계정 식별자를 제공하며, 앱은 Apple ID 암호나 이메일 주소를 받지 않습니다.

제안 취소 또는 문제 신고

어느 한쪽이라도 전달하거나 완료했다면 문제 상태로 표시되고, 해결될 때까지 묶음의 예약이 유지돼요.

게시물 신고

문제가 있으면 신고와 차단을 이용하세요. 모든 신고는 24시간 안에 검토하며, 규칙을 위반한 콘텐츠는 삭제되고 작성자의 계정은 정지돼요.

커뮤니티 규칙 · 지원팀에 연락

18세 이상만 이용 가능합니다. 낮 시간에 공개 장소에서 만나고, 어디로 가는지 친구에게 알려주세요. 커뮤니티 기능을 사용하려면 iCloud 계정이 필요합니다.
